# Formulário JovemTech

Projeto simples de formulário web destinado ao público JovemTech. Fornece um layout acessível para coleta de dados básicos, estilos responsivos e utilitários para validação e helpers.

## Funcionalidades

- Campos comuns: nome, email, idade e campos adicionais personalizáveis.
- Validação básica no frontend para campos obrigatórios e formato de email.
- Estilos responsivos em `style.css` para visualização em dispositivos móveis e desktop.

## Tecnologias

- HTML: `index.html`
- CSS: `style.css`
- Scripts/Auxiliares: `Utilitarios/`

## Estrutura do repositório

- `index.html` — página principal do formulário.
- `style.css` — estilos do projeto.
- `Utilitarios/` — scripts e utilitários (validação, helpers).

## Como usar (local)

1. Abra `index.html` no navegador (duplo-clique ou arrastar para o navegador).

2. Opcional — servir localmente com um servidor simples (requer Node.js):

```bash
npx http-server . -o
```
